# TrekUI Launcher

An Android home-screen launcher that replaces the phone's whole home experience: home screen, app drawer, search, a pull-down shade, a dialer, live panels, widgets and start-up sequences. Everything is drawn in code on a Canvas, in one of eleven interfaces:

- five starship consoles (Command, Classic Console, Next Console, Imperial, Collective)
- six "Pipe Lounge" interfaces, built around a pipe collection, from Victorian cabinets to painted scenes

It runs on Android 8.0 (API 26) and newer, on phones, tablets, foldables and in multi-window. It needs no root, account or server.

> **Original work.** TrekUI Launcher is an independent design: every frame, glyph, font and synthesized sound is drawn or generated by this project. No third-party recordings or artwork ship with the app.

**Screenshots, videos and test results:** <https://gungreeneyes.github.io/TrekUI.Java/>. CI regenerates the site on every release from emulator runs on phones (API 26 to 36), a landscape phone, a tablet and a foldable. Each GitHub Release also includes the media as `site-media.zip`.

## Interfaces

Choose the interface in **CONFIG › INTERFACE**: first the family (STARSHIP or PIPE LOUNGE), then the interface. Every function works the same in all eleven: tiles, dock, assignable elements, sounds, drawer, shade, dialer, CLOAK, smart devices, panels and the start-up sequence. Only the geometry, lettering, colours and materials change.

### Starship family

| Interface | Look | Home layout options |
|---|---|---|
| **Command** | Curved elbows, solid colour keys, Antonio type, eleven colour themes (CLASSIC, DEEP BLUE, SUNSET DECK, NIGHT PADD, STELLAR SILVER, MODERN GRAY and more) | Classic frame, or **CONSOLE CASCADE**: one key that deploys a spine of tiles |
| **Classic Console** (23rd-century style) | Chunky square console keys in primary colours with a bevel, rows of indicator lamps (some blinking), no elbows, Josefin Sans lettering, three colour themes | Same as Command: grid or **CONSOLE CASCADE** |
| **Next Console** (25th-century style) | Thin translucent blue/grey glass layers, 1dp outlines with 45° cut corners, fine tick rules, light Antonio lettering, three colour themes | Same as Command: grid or **CONSOLE CASCADE** |
| **Imperial** (Imperial Tactical) | Chamfered octagon plates, triangle lattices, blood red and amber (or one of four more colour themes), the project's own *Warrior Blade* lettering | Classic, or **TACTICAL DEPLOY**: tiles slide out as an arrowhead |
| **Collective** | Glowing nodes on circuit traces, no hard edges, Share Tech type, five colour themes (matrix green, cyan, amber, violet, frost) | **TRACE COLUMN**, or **HUB AND SPOKE**: nodes in orbit around a central hub |

Each starship interface also has:

- **INFO › STATIONS**: six toy bridge consoles (OPS, CONN, TACTICAL, ENGINEERING, SCIENCE, MEDICAL), clearly marked SIMULATION.
- **Its own start-up sequence**: a console power-up, a 23rd-century console switching on key by key, 25th-century fine lines drawing themselves, an Imperial triangle assembly, or the Collective network linking up.

### Pipe Lounge family

| Interface | Kind | Materials |
|---|---|---|
| **The Tobacconist** | drawn | Victorian cabinet: walnut, brass, oxblood |
| **Ember Lounge** | drawn | Art Deco smoking room: lacquer, gold, ember |
| **Blend Journal** | drawn | Tobacco-barn ledger: leather, kraft paper, red ink |

| **Tobacconist's Ledger** | painted scene | A merchant's bound folio |

The painted-scene homes show a painting with live overlays (clock, weather and so on). Its objects work as launcher slots. They also open the collection pages: pipe register, blend catalogue, smoking journal, ritual and session clock, reference shelves, and export/import. The collection is stored only on the device.

## Features

- **TrekUI Messages (companion app):** a full default SMS/MMS app in the same interfaces: conversations, picture messages, search, drafts, blocking, dual SIM, notifications with inline reply. Follows the launcher's interface and sub-theme, works on its own too. See [docs/MESSAGES.md](docs/MESSAGES.md).
- **Launcher basics:** the full app list via Android's `LauncherApps` API (work profile and Secure Folder included), search, categories, hidden apps, uninstall, app shortcuts, and clip-reveal launch animations.
- **Assignable everything:** long-press any tile, dock slot, elbow, bar segment, code block, title, clock or date. You can assign an app or a launcher function, rename it, recolour it, or give it its own sound.
- **Live panels:** these refresh only while home is visible.
  - Chronometer, with an optional stardate.
  - Power: battery, charging and temperature.
  - Weather from Open-Meteo.
  - Calendar.
  - Media, with source buttons for any player.
  - Ship systems: CPU, memory, storage and network graphs.
  - Android widgets: any other app's widget in its own framed panel (up to 12).
- **Console shade:** swipe down on home for quick toggles, brightness and volume sliders, and a notification log with inline REPLY and the apps' action keys.
- **Unread badges:** tiles and dock icons of apps with notifications show an unread count, styled for each interface.
- **Console dialer:** a keypad with contact matching, recents and contacts. Calls go straight out only if you allow it. Emergency numbers always go through the system phone app.
- **CLOAK:** a timed night mode that dims the interface, the sounds and the screen brightness.
- **RED ALERT:** an assignable function that pulses a red alarm frame over the home screen in every interface and loops the RED ALERT sound, with MUTE and STAND DOWN on screen and an auto-timeout. It stays silent in Silent/Vibrate and Do Not Disturb, and touches pass through it.
- **First-run tour:** eight short stops in the current interface's style (long-press to ASSIGN, the drawer, the shade, CONFIG, switching interfaces, backup, set as default home). Skip it any time; replay it from CONFIG › DEFAULT HOME › REPLAY TOUR.
- **Your layout is never lost:** CONFIG › BACKUP exports the layout and appearance to a JSON file and imports it on another phone, with a preview first (smart-device keys, tokens and your weather location are never exported). Snapshots are saved automatically before app updates, imports, resets, restores and interface switches (the newest 10 are kept), with UNDO LAST CHANGE and RESTORE.
- **App groups:** OPEN GROUP is an assignable function that unfolds a named set of up to 12 apps in your interface's style: a cascading console with keys sliding out of a spine, an Imperial tactical deploy, a Collective orbit or a Pipe Lounge card. Create, rename, reorder and delete groups from CONFIG › APP GROUPS, from ASSIGN TREKUI FUNCTION, or with ADD TO GROUP in the drawer's long-press menu.
- **Gestures:** double-tap, two-finger swipe up and down, pinch in and out, and swipe left and right on home can each run any launcher function or app (CONFIG › GESTURES). Swipe up for the drawer and swipe down for the shade work as before.
- **LOCK SCREEN (optional):** locks the phone from a tile, element or gesture through an accessibility service that reads nothing (Android 9+). It is off until you agree to an in-app explanation and turn it on in Android's Accessibility settings.
- **Colour themes for every starship interface:** CONFIG › INTERFACE › COLOR THEME, with a preview strip per theme; the change applies at once and the TrekUI companion apps follow it.
- **TrekUI suite in one place:** CONFIG › SUITE shows the active keyboard and opens the keyboard picker, switches the TrekUI wake screen on or off, and makes TrekUI Messages the default SMS app (or restores the previous one). Companions that aren't installed get an INSTALL link to Google Play.
- **Quick Settings tiles:** CLOAK and RED ALERT tiles for the phone's Quick Settings panel (CONFIG offers to add them on Android 13+).
- **Icons your way:** 109 original pictograms drawn in every interface's style, matched automatically to common apps (banking, shopping, streaming, travel…). Any ADW/Nova-compatible icon pack from the Play Store works too (CONFIG › APP DRAWER › ICON PACK, with a preview), and long-press › CHANGE ICON gives a single app any pictogram, any pack icon or its own icon.
- **Smart devices:**
  - **Govee lights:** controlled over the local network (LAN API), or through the Govee cloud API with your own key.
  - **Nest thermostats:** controlled through Google's Smart Device Management API, with your own Device Access project.
  - **Home Assistant:** lights (on/off, brightness, colour), switches, fans, climate, scenes and scripts through your own Home Assistant's REST API and a long-lived access token (HTTPS, or `http://` to a `.local` name on your home network).
- **Theming help:** recipes and exported art for Samsung's Quick Panel (Good Lock), Signal, Chrome and the Samsung Keyboard.
- **Widgets:** two widgets for other launchers, TrekUI Chronometer and TrekUI Quick Launch.
- **Responsive layout:** works in portrait and landscape, from small phones to tablets, on foldables, and in multi-window, edge-to-edge with display cutouts handled.

The full feature history is in [CHANGELOG.md](CHANGELOG.md).

## Install

### Google Play

Search for the app on Google Play, or follow the link on the [project page](https://gungreeneyes.github.io/TrekUI.Java/) once the listing is live. The Play build is the `production` flavor, with application ID `com.gungreeneyes.trekui`.

### APK (sideload)

1. Download `TrekUI-<version>.apk` from [GitHub Releases](https://github.com/GunGreenEyes/TrekUI.Java/releases). For the latest development build, open the newest run of the **Develop** workflow under [Actions](https://github.com/GunGreenEyes/TrekUI.Java/actions) and download the `TrekUI-develop-debug-apk` artifact. You need to be signed in to GitHub to download artifacts.
2. Open the APK on the phone. If Android blocks it, allow **Install unknown apps** for the app you opened it from.
   - On Samsung, if the install is refused outright, turn off **Settings › Security and privacy › Auto Blocker** for the moment.
3. A develop build installs as **TrekUI Dev** (`com.gungreeneyes.trekui.dev`) next to the store build. You can keep both.

> APKs signed with different keys cannot update each other. If you used a 5.x/6.x sideloaded build, uninstall it before installing the Play build. Your layout is lost unless Android backup restores it.

### BlueStacks (Windows/macOS)

Use a BlueStacks instance running **Android 9 (Pie 64-bit) or Android 11**. Android 7 (Nougat) instances are older than the app's minimum, Android 8.0.

1. Drag the APK onto the BlueStacks window, or use **Install APK** in the side toolbar.
2. Inside BlueStacks, go to **Settings › Apps › Default apps › Home app** and choose **TrekUI**.

To install from the command line, enable **Settings › Advanced › Android Debug Bridge** in BlueStacks, then run `adb connect 127.0.0.1:<port shown there>` and `adb install -r <apk>`. The `scripts/bluestacks.*` helpers automate this.

### Termux (build and install on the phone itself)

The original developer built the launcher on the phone with Termux. To do the same:

```sh
pkg install git
git clone https://github.com/GunGreenEyes/TrekUI.Java && cd TrekUI.Java
bash scripts/setup.sh          # JDK 21, SDK, Termux aapt2, then a test build
termux-setup-storage           # once, so Termux can write to Downloads
cp app/build/outputs/apk/develop/debug/*.apk ~/storage/downloads/
termux-open ~/storage/downloads/app-develop-debug.apk
```

For more, see [docs/REMOTE_DEVELOPMENT.md](docs/REMOTE_DEVELOPMENT.md#4-building-on-the-phone-with-termux).

### Set TrekUI as the default home

Open **TrekUI** and accept **SET AS DEFAULT HOME**. You can also choose it later:

- Android: **Settings › Apps › Default apps › Home app › TrekUI**
- Samsung: **Settings › Apps › Choose default apps › Home app**

To go back, pick your previous home app in the same place, or uninstall TrekUI.

## Free to try, $0.99 to keep

TrekUI Launcher has **no ads** and **no subscriptions**, and every feature works from the first launch.

- **Trial sessions:** without a licence, each session lasts 24 hours. When a session ends, the next time you return to the home screen, a screen offers the one-time **$0.99 unlock** (Google Play in-app purchase). You can also start another session or switch to a different home app.
- **Never interrupts other apps:** the screen appears only on the home screen, never over another app. A reboot also starts a new session.
- **The unlock:** it is permanent, restores automatically on your other devices signed in to the same Google account, and works offline once granted.

Develop builds use 5-minute sessions so the flow can be tested. Pricing and design notes are in [docs/MONETIZATION.md](docs/MONETIZATION.md).

## Sounds

**The app bundles no recordings.** It ships only its own synthesized sounds; third-party recordings are copyrighted, so none are shipped in the APK or committed to this repository. You add recordings in one of two ways:

- **Download:** go to **CONFIG › AUDIO SYSTEMS** and use **DOWNLOAD SOUND LIBRARY**. The app fetches each clip from the public web page it is catalogued under, checks its SHA-256 checksum, cuts it on the phone and keeps it in app-private storage. The clips are never backed up or uploaded. The catalogue is `app/src/main/assets/sounds/manifest.json`.
- **Import:** import your own audio files or a ZIP. Clips can be up to 40 seconds and become available for every event, element, ringtone or alarm.

Without recordings the launcher plays its synthesized sounds (or stays silent), and nothing breaks. See [docs/SOUNDS.md](docs/SOUNDS.md).

## Build from source

You need JDK 21, the Android SDK (platform 37, build-tools 37) and Git. The setup scripts install everything on a fresh machine and then run a test build:

```sh
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1      # -WhatIf previews, -Emulators adds AVD images
# macOS / Linux / Termux
bash scripts/setup.sh                                          # --dry-run previews, --emulators adds AVD images
```

Then:

```sh
./gradlew assembleDevelopDebug          # app/build/outputs/apk/develop/debug/
./gradlew testDevelopDebugUnitTest      # JVM + Robolectric tests
./gradlew :app:dist                     # every APK/AAB copied to dist/
```

More detail is in [docs/BUILD.md](docs/BUILD.md), [docs/TESTING.md](docs/TESTING.md) and [docs/RELEASE.md](docs/RELEASE.md). The code structure is described in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Privacy

Your data stays on the device. The launcher has no analytics, no ads and no account. The only network requests are ones you turn on: the weather lookup, your own Govee, Nest or Home Assistant devices, sound downloads, and Google Play for the purchase. Details are in [PRIVACY.md](PRIVACY.md).
